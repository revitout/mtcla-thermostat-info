MTCLA Thermostat Remote

Dedicated temperature controls for one church.

This application connects a dedicated physical controller to an authorized Google Nest thermostat. It gives approved church operators a simple way to adjust temperatures, choose heating or cooling modes, and turn the system off.

A focused controller

  • TemperatureView the room temperature and adjust the thermostat's targets.
  • ModeChoose supported Heat, Cool, or Auto modes.
  • System statusCheck the heating, cooling, idle, or Off state reported by the thermostat.
  • OffUse a prominent control to request that the thermostat turn off.

How access works

The administrator authorizes access through Google's sign-in and consent screens. The controller uses Google's Smart Device Management API for the selected thermostat. Its normal controls expose the temperature and mode functions chosen for this installation.

This is a one-off church project. These public pages describe the application and its data practices; thermostat operation takes place on the installed controller.

Limited to thermostat operation

Thermostat readings and authorization credentials are used to provide the remote's controls. See the privacy policy for the data accessed, where it is kept, and how authorization can be removed.

Support

For application or privacy questions, contact the maintainer through the project's GitHub Issues page. Anyone using the installed controller can also contact the church's thermostat administrator directly.

GitHub issues are public. Keep passwords, authorization links, tokens, and other private information out of support requests.
